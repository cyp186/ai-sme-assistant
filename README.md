# AI Business Assistant

## Overview

AI Business Assistant is a web application designed to help small and medium-sized businesses manage customer enquiries and generate AI-powered response drafts.

## Features

- User authentication
- Customer management
- Enquiry management
- Business knowledge base
- AI-generated responses
- Dashboard analytics

## Tech Stack

### Frontend
- React

### Backend
- FastAPI

### Database
- PostgreSQL

### AI
- OpenAI API
